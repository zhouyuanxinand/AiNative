# 小航天气、轻快陪伴与对话面板

**Goal:** 小航默认提供洛阳涧西天气、短暂原地动作、可唤回的贴边隐藏，以及无需先选择案例的输入对话。

**Architecture:** 沿用 React、现有人物帧图、FastAPI 和项目助手。天气由同服务中的 MCP 工具及 HTTP 读取接口提供；业务案例问答保持原接口。未选案例时提供平台操作问答和明确的导航动作，聊天建议不自动执行业务写入。

**用户决定:** 轻快陪伴、原地小动作、偶尔天气气泡；拖至左右边缘可隐藏；欢迎弹窗升级成可输入的对话框；天气服务一并实现。

## 实现与验收

- [x] 天气服务：默认涧西坐标 34.65878,112.3866，免密钥 MET Norway 预报、10 分钟缓存与失败状态；可配置外部 MCP，内嵌 MCP 提供 initialize/tools/list/tools/call。
- [x] 人物：探头、轻摆、小跳、挥手，8–18 秒静默间隔，不连续重复；暂停、后台、减少动态效果时静止。
- [x] 拖拽：仅主动拖到左右 24px 边缘松手才隐藏；保留24px唤回标签、键盘入口和 Home 复位；普通贴边位置不自动隐藏。
- [x] 天气 UI：只在闲置时短暂出现，至少5分钟间隔；收起/拖拽/输入/后台不打扰；对话内可主动查看，显示来源与预报时间，不造数据。
- [x] 对话：沿用矿物蓝主题，统一头部、消息、问题建议、输入区；中文输入法、Enter/Shift+Enter、发送状态、失败保留输入、关闭后保留会话。
- [x] 验证：仅新增天气/对话与小航相关测试文件，TypeScript及构建、桌面/窄屏/键盘/减少动态效果和失败路径；失败先复现定点修改。禁止无筛选全量。

## 约束与风险

复用当前正在运行的 rd-platform-rebuild-20261031 工作树，保留已有未提交改动。天气是全球模型预报，显示数据来源，不能冒充中国气象站实况或预警。MCP及天气数据读取不获得业务写权限。缩小动画仅变换内部人物，保持拖拽测量边界稳定。聊天采用显式按钮导航，不能自动创建/删除/批准。
