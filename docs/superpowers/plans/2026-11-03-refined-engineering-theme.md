# 研发工作台字体与专业视觉精修

## 本轮决定

用户要求免费字体及更高级、专业的整体风格，继续沿用已指定的 Ant Design。采用精密工程工作台方向：石墨导航、雾灰背景、矿物蓝操作、白色工作面；通过排版、对比、分区与间距体现层次，不加入虚构统计或装饰性业务编号。本轮按用户授权直接实现，先记录方案再改代码。

考虑了亮蓝通用控制台、全深色驾驶舱、浅色精密工程工作台三种路径。选择第三种：最适合长时间阅读中文需求、表格与画布；全深色不适合文档工作，单纯亮蓝无法回应本次质感要求。

- 颜色：主操作 #236a83，页面 #eff3f6，工作面 #ffffff，正文 #223241，辅助 #617384，边框 #dce4eb；导航 #142632。危险、成功、警告继续使用 AntD 语义色。
- 字体：优先思源黑体简体中文开源字体，本地 WOFF2 资源，保留许可证与来源；数据使用免费开源等宽字体。确认字体文件与授权后，记录确切版本、大小及浏览器加载证据。避免整个大字体阻塞首屏；需要时拆分 unicode-range。
- 排版：标题24/20/16px，正文14px，辅助12/13px；中文不加人工字距。标题600、正文400、标签500。技术编号等宽，表格数字对齐。
- 布局：保持216px导航/64px顶栏/32px桌面页边距与24px面板内边距；窄屏回到12/16px。保留32px紧凑工具栏；长内容有完整滚动。主要分区以边线和浅灰分区背景组织。
- 标识性细节：导航选中采用低饱和蓝底和细色边，白工作面的标题/工具区有明确分隔；保留JONHON标志与工程术语。

## 实施

1. 获取官方开源字体及许可证，离线接入，维护来源、可重建方式和资源体积。
2. 在 PlatformTheme 统一修改 AntD 与 CSS 令牌，平台壳/首页/管理列表调整排版和层次。
3. 流程目录、完整画布、版本工作台与资源目录同步精修；保留节点210×108几何、依赖关系与交互。
4. 管理、帮助、弹窗与项目办理消费同一主题；修正明显旧样式覆盖。
5. 检查字体实际加载、无外网字体请求、桌面和390px、长标题/空列表/有数据状态、筛选对齐、画布节点边界；截图后视觉复核。运行一次构建及受影响的已有布局/画布测试文件，不运行无筛选全量，不放宽断言或超时。
