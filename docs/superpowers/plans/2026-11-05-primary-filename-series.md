# 产品系列仅由主需求文件名识别

## 目标与边界

用户确认：产品系列只识别需求文件主文件的文件名。例如 `YLZJ-BG-469液冷组件规格书(JONHON受控).doc` 应识别为 `YLZJ`。不再从正文、封面、产品规范或补充资料提取系列；工程指标仍依原文提取，生成引擎与受控模板规则不变。

## 开发步骤

1. 按用户随后明确的规则实现：按 `source_selection.tech` 选择主需求文件，历史单一需求来源仍兼容；去掉扩展名，从左到右取第一个连续英文字母串并统一大写，不做语义猜测或数字型号解析。例如 `YLZJ-BG-469`→`YLZJ`、`CY43`→`CY`、`J599L`→`J`。文件名没有英文字母时留空，保留后续明确确认入口。
2. 资料分析的系列候选仅使用该规则，忽略模型正文系列提案；保留文件名、来源 ID、版本与哈希证据，采用仍由用户明确确认，已有用户确认不静默覆盖。
3. 自动补齐与一致性检查复用同一规则，避免正文完整型号或规范旧型号重新覆盖/误报；其他业务参数、需求指标与门禁不变。
4. 同步界面提示及设计约定。已有历史分析不静默重写，重新分析后应用新规则。

## 验证范围

- 先用真实文件名复现错误候选，增加定点回归；覆盖主文件选择、忽略厂商/正文/规范/补充资料、无法识别、证据采纳与失效、手工确认。
- 仅运行受影响的系列分析、来源分析、参数依据及执行器测试文件；若失败，先定点定位修复再运行该完整文件。旧的封面识别断言按新业务规则调整，保留其余证据、安全与版本断言。
- 界面仅调整说明文字；不执行无筛选全量，不发起真实模型生成或修改已有用户项目。
