# 资料识别页布局精简

## 目标与边界

按用户截图优化当前资料识别页面，降低标题与说明的重复、缩短到上传和分析操作的距离。沿用 Ant Design、RD Sans 与已有蓝绿令牌；不改模型保存分析、上传采用、业务决定、权限和生成逻辑。

## 设计

- 项目导航、刷新和记录保留紧凑同一行，普通状态信息缩小留白。
- 客户、产品及研发目标保持可读，去除这一区域重复的流程模板文字；流程固定版本在案例标题处呈现。
- 资料编辑页合并为单一“资料识别与项目信息”主标题，案例及流程名称作副信息，返回与阶段状态归到同一标题区。其他工作面保留原结构。
- 删除阶段指导与来源工作面重复说明；上传区只保留“编制资料”、必要字段提示和文件状态。
- 分析区简化为“资料分析”及一句采用提示；不删除来源证据、缺项、冲突和失败提示。
- 资料工作面的标题、上传、分析卡共用宽度，统一间距；700px以下自然换行，不固定整页高度，不隐藏长内容。

## 实施与验证

1. 调整 RdPlatformPage、CaseWorkspace、ScenarioWorkspace、CaseInputForm、SourceAnalysisPanel 的显示结构/文字，局部样式由业务布局类维护。
2. 更新现有设计/交互约定，不引入新的主题或控件。
3. 浏览器验证1440/1920桌面和390px窄屏、长项目名与文件名、空资料、分析结果、错误状态及返回其他工作面；保留截图。
4. 只执行直接受影响的资料分析浏览器文件和前端构建。复用上一轮模型/MRU结果，不运行全量，不修改真实项目或调用真实模型。

## 用户追加（同轮）

- 将“项目空间 / 项目名称”面包屑移到平台名称下，替换原单独项目名，正文不重复。
- 客户、产品、研发目标改为更明确的项目摘要面板，保持紧凑。
- 文件卡片按类型显示图标、删除操作；超过30个字符时缩写并可查看全名。桌面最多两列，更多换行，窄屏单列，移除资料记录折叠。
- 删除接入后端资料管理，保留历史执行来源可追溯，不能只隐藏页面或物理破坏历史成果。沿用权限、运行锁、输入修订失效及审计机制；以定点后端测试和隔离浏览器验证。
- 修正流程模板副标题中的 Vundefined。截图检查发现的移动端标题对齐同时修复。
- 资料页助手入口放入标题操作区，保留对话状态与其他页面悬浮入口，避免遮挡分析按钮；页面错误统一一处呈现，弹窗内失败不抢焦点。
- 普通操作通知使用 Ant Design Message，3秒自动消失；错误及需要确认的弹窗继续保留。文件卡片宽度按内容收紧、背景使用浅色，同排最多两张。
