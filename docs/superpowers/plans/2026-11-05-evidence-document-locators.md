# 原文引用定位 ID

用户要求把需求清单“核对来源原文”里的长文件名改为文档内部定位 ID，便于之后定位。

## 实施

1. 用来源原件的校验值、版本和实际文档坐标生成定位记录。优先复用现有证据读取器的正文块、表格行或文本行坐标，不用需求序号或模型生成的 ID 冒充原文位置。
2. 增加受现有项目权限保护的只读定位接口，从已保存的原文引用解析位置，兼容已有分析结果，不重新调用模型、不修改原件或采用记录。重复原文列出全部候选位置，未匹配明确提示。
3. 办理页统一显示短定位 ID、位置含义；原文件名和版本收进悬停提示，仍可打开原件。全文审阅与需求确认复用。定位只代表内容坐标，不声称 Word 下载链接能自动跳到段落。
4. 页面共享一次定位读取，隔离项目、流程和账号；加载失败可重试，不影响原文或草稿。现有项目登记和文件名依据不伪造正文位置。

## 验证

定向覆盖段落、表格行、文本行、重复原文、无匹配、历史来源、权限和文件校验。浏览器检查主表/全屏、文件提示、失败状态及原操作保留；执行前端构建。只验证受影响文件，不执行无筛选全量。
