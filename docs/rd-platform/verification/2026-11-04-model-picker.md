# 编制模型选择与最近使用验证

日期：2026-11-04。分支：`codex/rd-platform-rebuild-20261031`。本轮未提交代码。

## 最终行为

- 下拉显示厂商和完整模型名，例如“微软 Azure · azure/gpt-5.4”“阿里云 DashScope · dashscope/qwen3.5-plus”。沿用 Ant Design StyledSelect。
- 默认值显示“使用平台默认模型”；选项按 provider/name/id 稳定键匹配，服务端 JSON 字段顺序不再影响选中标签。
- “最近使用”展示当前服务端账号在当前浏览器成功保存的最近 5 个非默认模型，去重且最近在前。未保存、保存失败、默认选择不写历史；不自动覆盖项目当前选择。
- 目录中不存在或未就绪的模型不进入最近分组。缺失的已保存当前模型保持可读，目录读取失败保留重试入口。
- 返回标签页和成功保存后重新核对身份；失败或换号不串写。身份轮次防止迟到响应恢复旧账号；成功保存的校验按顺序处理，不阻塞继续选择和保存。

实际调用仍传原 provider/name/id，未改后端生成引擎、资料分析、质量门禁或任何真实项目设置。最近选择不是模型调用审计，页面已说明其记录范围。

## 验证范围与结果

1. `web/src/features/rd/modelSelection.test.mjs`：6/6 通过。稳定键、厂商信息、目录分组、历史缺失项、每账号最近五条、缓存损坏/禁用。
2. `web/tests/rd-model-picker.browser.mjs`：最终完整文件 10/10 组通过。真实 CaseInputForm / CurrentUserProvider / StyledSelect，所有接口均被隔离夹具接管。
   - 默认及厂商展示；成功保存刷新后仍在；仅选择/失败/默认不记。
   - 上限五条、去重及最近排序；账号和 origin 隔离；目录缺失、未就绪、目录/会话失败与恢复。
   - 390px 下纯键盘选择和保存、无横向溢出。
   - 同页换号、连续保存身份响应乱序、A→B→A 后旧校验迟到；不串写且不覆盖新身份展示。
3. TypeScript `tsc` 和 Vite 生产构建通过。构建保留已有单块超过 500KB 的体积提示，不影响成功产出。

浏览器回执：14 次保存均为夹具（含显式失败），2 个延迟身份响应，真实 API 请求 0，页面异常 0，非预期请求 0。原断言和 15 秒操作超时保留。独立只读复查发现的身份边界均已复现并闭环。

未运行无筛选全量测试、真实模型调用或任务书生成；既有数据逻辑通过结果在 helper 未变化后复用，不重复验证无关文件。
