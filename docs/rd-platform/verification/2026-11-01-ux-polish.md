# 研发平台 UI/UX 优化验证

实施始于 2026-11-01，收尾验证于 2026-11-02。分支 `codex/rd-platform-rebuild-20261031`，在既有未提交 P2/P3 工作上继续，未自动提交或推送。

开发计划先于本轮产品修改形成：[体验优化计划](../../superpowers/plans/2026-11-01-rd-platform-ux-polish.md)。本轮只改前端交互、局部样式、浏览器测试与设计资料；原任务书生成引擎、后端命令、业务批准和正式交付规则保持。

## 用户可见变化

| 区域 | 改善 | 行为边界 |
|---|---|---|
| 业务模板 | 取消编辑；有修改时可继续编辑或确认放弃；失败后仍可退出 | 取消没有写请求，不创建副本记录 |
| 项目工作包 | 当前状态与下一步提示，解释未保存、候选过期、待采用、阶段受限和运行只读 | 保存、准备、采用与执行分开 |
| 节点画布 | 标题加序号的节点导航、定位节点、跳转属性；新增与复制后可见 | 只滚动视口，不改坐标或触发执行；键盘入口保留 |
| 团队目录 | 加载/失败/空态分开，保留草稿独立重试 | 撤权清除受限状态，迟到请求不恢复 |
| 模板治理 | 候选与待办前置；准备候选、维护规则和技术证据按需展开 | 审核专用身份不显示创建区；缺项提示不替代后端门禁 |
| 表单 | 首错展开与焦点、字段说明、禁用原因、未保存定位和操作附近错误 | 折叠保留文件和字段；保存失败保持同意图重试 |
| 资源团队 | 只读内部图收起，编辑区内部图上下布局，JSON 放入高级配置 | 原始 JSON 和图共用一份数据；标签 ID 按实例唯一 |
| 补缺证据 | 停止原因、记录计数及待补项前置，轮次和原文详情折叠 | 零值与未记录分开；停止不意味着正式交付通过 |

## 独立复核与修复

独立代理只读复核发现两项真实问题，均已修复并再次复核通过：

1. 团队高级 JSON 中语法合法但结构不完整的内容会导致 React 渲染异常。现在仅检查可视化所需结构，提示修正并保留原值；修正后恢复显示。覆盖 `members: {}`、`inputs: {}`、缺失图数组、空节点和对象类型版本号；此检查不宣称满足服务器发布条件。
2. 候选审核/发布的通用成功回调会错误清除另一份准备表单的未保存状态。现在按字段保存快照，只确认实际写入本次请求的字段；来源、依据、JSON、目标和文件均参与离开保护，正常绑定初载不误报，401/403 清除受限填写。

首项由主代理和复核代理分别跑浏览器验证；第二项先用新增断言复现失败，再修改并通过。最终复核无残余阻断问题。

反馈测试原后半段仍依赖已退休的生成主页 `#workspace-shell`。现改为明确的组件集成夹具，保留反馈位于下载上方、缺项验证、防连点、503 幂等重试及下载链接可用性。没有为使测试通过而恢复旧首页，也不将此夹具称为新主页端到端测试。

目录旧回归原先假设始终为五个本地动作，且 v1 工作包仍使用 `save_plan` 编辑表面。现在目录按真实授权页的项目数量和 ID 验证，旧工作包夹具经 `create_flow_draft` 进入统一编辑器，保留增删、依赖、失败重试和只读断言，并明确校验准备、采用和提交分别发生。不为旧测试重新开放退休的前端路径。

## 已知范围与限制

严格 UI 静态审计运行完成，结果仍有 **21 项既存发现**；与本轮前 P2/P3 审计按文件、规则和消息比较，新增 0 项。旧管理/审阅表单、共享下拉的隐藏原生镜像、滚动条等记录未在本轮全部改造，不能宣称全站严格静态检查通过。详见 [本轮审计](2026-11-01-ux-premium-audit.json)。

生产构建仍提示主 JS 包超过 500 kB（本轮约 584 kB，gzip 187 kB），没有宣称完成性能拆包。浏览器使用本机现有 Chromium；本轮没有旧 Chrome 104 实机验证。由于没有后端或生成语义修改，未重复调用模型生成文档。
