# 能力建设与运行平台的一手资料研究

核验日期：2026-10-28。范围是专家、技能、组合流程的版本与执行管理，为四平台方案提供设计参考，不进行产品选型或代码改造。

## 调研方法与边界

Agent-Reach 从用户指定的官方 GitHub 源码安装到本地隔离工具环境，版本1.6.0，提交 `14c213405669414492bda0f8d52cc6531d062c45`。主研究及制造PLM研究已用其 `web search` 获得官方结果；随后公开Exa通道返回429，Agent-Reach对整个web渠道进入约一小时冷却。本研究使用内置网页检索与官方页面直接核验，没有修改冷却配置或使用登录渠道。

只采纳厂商官方文档及项目官方文档；搜索结果中的镜像站、社区问答和二手教程没有作为能力结论依据。云服务文档仅证明其公开设计，不证明本项目可直接使用同等能力、许可或内网部署方式。

## 核实的设计模式

| 一手来源 | 已核实事实 | 对本方案的启示（研究推论） |
|---|---|---|
| [Microsoft Foundry 部署与版本](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/deploy-hosted-agent) | 部署产生Agent版本；生产端点可以固定版本，并经明确操作切换 | Workspace发布能力与研发项目采用分开，项目固定引用不自动跟随最新版本 |
| [Microsoft Foundry 权限](https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/hosted-agent-permissions) | 用户、项目身份和Agent身份有不同权限；消费与管理权限有区别 | 平台管理员权限、项目业务权、服务委托权分别核验，技术管理员不能代工程人员审签 |
| [Dify 版本管理](https://docs.dify.ai/en/cloud/use-dify/build/version-control) | 草稿、当前发布版及历史版分离；恢复历史版先进入草稿；指定版运行有产品计划限制 | 借鉴受控制品生命周期，不直接照搬“所有调用跟随最新发布版”或删除历史版策略 |
| [Dify 成员管理](https://docs.dify.ai/en/cloud/use-dify/workspace/team-members-management) | 建设者、管理者和已发布应用使用者有区别；知识库另有访问权限 | 建设权限与使用权限分离，能调用能力不等于能读取其全部知识 |
| [LangGraph 持久化](https://docs.langchain.com/oss/python/langgraph/persistence) | 检查点保存线程内执行状态，store保存跨线程数据 | Runtime检查点不替代研发工程事实库；应明确运行恢复与业务状态的不同职责 |
| [LangGraph 中断](https://docs.langchain.com/oss/python/langgraph/interrupts) | 执行可等待外部决定后恢复；恢复时节点中断前代码会再次执行 | 可采用等待人工的运行机制，但工程批准仍须校验身份、版本、证据和幂等，不能把恢复信号直接当作批准 |

上述文档没有定义连接器研发项目的专业通过标准。它们也没有证明一个通用工作流工具已经具备企业的独立审签、模板有效性或工程变更制度。

## 对四平台的具体建议

1. Workspace维护固定能力制品、评测、发布和应用投放。本体维护动作语义、前置条件及输入输出契约，研发持有项目采用和实际办理记录；不要把三个层次合并成“发布一个流程”。
2. 研发业务流程调度由原方案C02负责，受限调用与Run适配由C03承担；Runtime返回执行进展和候选。K-box治理流水线仍由K-box持有其治理作业，Workspace持有资源发布过程，单一Owner约束按所属业务域落实。
3. 候选准备、人工采用、工程批准、业务发布和外部接收分别记事实。运行完成只能说明工具完成一次执行。
4. 能力版本、语义版本、知识版本和项目输入版本共同形成一次受控执行上下文。后续变更先评估实际消费者，不覆盖既有采用历史。
5. 当前任务书生成器可作为一项固定能力被适配调用。先保留原输入/原文处理/QA，再设计有证据的人工补齐，不迁移成另一套自由生成链。

## 本轮不作出的决定

不据此推荐采购Microsoft云服务，不强制采用Dify或LangGraph，不把云端权限模型原样搬入内网。部署、许可证、既有厂商能力、数据访问边界和接口Owner须在原实施台账中确认。业务验收优先于工具选型。
