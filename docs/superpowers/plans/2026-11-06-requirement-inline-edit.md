# 需求表格行内修订

依据：用户要求直接在表格修改需求，不跳到页面底部。

## 实施范围

1. 点击“编辑需求”后，在该行编辑标题、需求内容；操作列提供保存、取消。一次编辑一行，保留关联来源的折叠选择。底部表单仅用于新增需求。
2. 原始指标及定位证据保留只读，已修订的当前记录在本行显示，避免保存后仍只看到旧快照。普通修订不产生实际结果，仍由采纳规范建议或采用澄清形成。
3. 复用 save_requirement 与现有版本失效规则。成功才清除编辑状态；失败留存输入并行内提示。版本变化后禁止覆盖新数据；未保存编辑继续受现有离开保护管理。
4. 沿用 Ant Design、已有主题和来源选择组件。编辑时避免其他决定或重新核对覆盖当前编辑；搜索筛选保留正在编辑的行。

## 验证

- 前端 TypeScript / 生产构建。
- 独立行内编辑浏览器用例：原位编辑、保存/取消/失败重试、原文与实际结果边界、只读与窄屏。
- 完整运行直接受影响的需求决定浏览器文件。不运行无筛选全量，不修改真实项目数据或重新调用模型。
