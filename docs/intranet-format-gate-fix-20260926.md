## 本次修复

| 问题 | 已复现的原因 | 修复 |
| --- | --- | --- |
| 普通来源表内字体字号不统一 | 来源表保留混合字体字号；显式字体可能仍受来源主题字体属性影响 | 来源表统一为既有表格字体规范，清理主题字体覆盖；保留表格结构、文字、加粗及人工填写规则所需的斜体证据 |
| 表内图片只显示一条或被裁切 | 固定行距和固定行高不能容纳图片；来源样式继承的固定行距同样会触发 | 图片段落允许自动撑高，图片所在行改为最小行高，覆盖 DrawingML 与 VML 图片；不改图片字节、裁切参数或几何尺寸 |
| 图题字号异常、与图分到不同页 | 导入来源图题保留过大字号、强制分页；多图最后一图同段含题注的连接规则不完整 | 规范导入图题，移除来源强制分页，建立相邻多图与图题的连续关系，保留模板原有图题格式 |
| 已复制内容仍被语义执行门禁阻断 | 图片复制后 Word 关系编号变化，XML 不再相同；低置信分支未按完整图片题注组验证 | 在目标章节核验实际引用图片的内容，并验证完整图片题注组；仅存在题注、图片在错误章节或图片内容不同均不能放行 |
| 隐藏内容被视为已展示 | 仅有相同媒体字节不足以证明内容可见 | 目标证据排除直接隐藏、删除和移出内容；低置信仍阻断，高置信按来源补齐可见内容 |
| “安全跳过”之后又报错 | 旧日志将全部 skipped 条目都称为安全跳过，其中实际包含阻断项 | 分别记录复制、已验证存在、安全跳过及阻断数；输出目标槽位、来源、操作、实际及最低置信度 |
