# 项目删除角标与完整操作计划

**目标：** 在项目列表卡片右上角及项目详情操作区显示项目删除图标，负责人确认后删除整个项目的普通访问入口。截图中的业务流程卡片属于项目内部对象，本轮删除对象为整个项目，不把单条流程按钮伪装成项目删除。

**现状与方案：** 后端尚无项目删除能力。复用反馈等既有 CRUD 的逻辑删除方式，记录删除人、时间、事件和版本，保留来源文件、执行成果和固定版本凭据。普通项目读取、下载、助手及关联使用列表均不再暴露已删除项目；删除不是清理磁盘文件的命令。只添加功能，不删除任何现有真实测试项目。

**业务约束：** 只有项目负责人可操作；提交中、运行中或持有有效执行租约时禁止删除。删除以 expected_version 和 Idempotency-Key 固定同一次请求；网络异常保留可重试，版本冲突保留弹窗并允许重新读取目标后再次确认。非负责人入口不展示，可删但运行受限时显示禁用图标及原因。

**交互：** 复用 Ant Design DeleteOutlined/Button/Tooltip 与 FeedbackConfirmDialog，图标始终可见，键盘有可读名称和焦点。确认框标明项目名、包含的流程数量及来源/成果访问影响，明确逻辑删除与保留追溯记录。取消不写入；成功移除列表、修正分页，删除当前项目时返回项目空间；失败不假装成功。正在请求时遮罩与 Escape 不取消尚在处理的请求。
