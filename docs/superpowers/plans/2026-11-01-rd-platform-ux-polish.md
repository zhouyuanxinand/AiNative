# 研发平台使用体验优化计划

用户要求优化使用细节和前端 UI/UX。本计划在本轮产品代码修改前形成，沿用已确认研发平台及 P2/P3 能力，当前分支 codex/rd-platform-rebuild-20261031。已有未提交功能全部保留；本轮不自动提交。

## 设计选择与范围

目标用户为编制任务书的工程人员及维护资源/模板的管理员。让用户先看见当前结果、下一步和阻碍原因，再按需要查看技术证据。保留 JONHON 蓝白工程工作台、已有中文字体、令牌和共享控件。

选择在现有页面内逐步展现信息：相比整体换肤，它能直接改善已发现的操作障碍；相比强制分步向导，它保留熟练用户直接查看候选与跨区校验的能力。此为本轮实施选择，不引入新业务审批或外部组件库。

视觉特征是紧凑的“当前状态—下一步”提示和清楚的分区标题。白色工作面、浅灰底、蓝色主操作、警告/成功语义色继续由 styles.css 的 color/font/radius 令牌提供。标题沿用系统中文无衬线，技术 ID 使用现有等宽字体并按需展开。桌面画布+属性双栏，窄屏自然单列；不能锁死整页滚动。

本轮不改变原任务书生成链、后端接口、权限、发布审核、工作包自动执行规则和正式交付门禁。P4/P5 不纳入。

## 复用与职责

| 能力 | 现有归属 | 本轮处理 |
|---|---|---|
| 下拉/键盘选择 | StyledSelect | 节点导航及原有目录继续复用 |
| 弹窗/放弃确认 | FeedbackConfirmDialog / FeedbackDialog | 取消模板编辑复用，继续支持遮罩与 Escape |
| 离开保护 | useApplicationLeaveGuard | 保留，局部取消不清除其他页面草稿 |
| 图表草稿 | FlowGraphEditor / flowDraftReducer | 定位只滚动画布，不写位置和提交事实 |
| 错误与异步回执 | 现有 rd-error/rd-notice/rd-success + epoch/abort | 就地提示、重试、保留输入；不另建通知系统 |
| 表单 | 现有 label/aria-invalid/描述与首错焦点模式 | 仅将现有验证映射到字段，不新增工程规则 |
| 原始证据 | native details + readable | 默认折叠，保持完整可访问 |

## T1 流程编辑体验

责任文件：FlowDesigner.tsx、FlowGraphEditor.tsx、WorkpackagePanel.tsx、BusinessWorkflowPanel.tsx、flowDesigner.css（仅图/流程选择器），相关独立浏览器测试。

- [x] 业务模板增加取消编辑：无修改直接退出，有修改确认后恢复服务端图/标题，副本取消不产生记录。保存失败也可退出，处理中不可重复操作。
- [x] 流程摘要明确未建草稿、未保存、待校验/准备、待采用、可提交、过期/阶段受限及运行只读状态和下一步；保留保存、校验、采用、提交的独立语义。

- [x] 获准专家团目录区分加载、失败和空目录；有草稿时仍能独立重试，权限变化不恢复过时数据。

## 验收

- 业务行为：取消无写请求、继续编辑保值、保存失败可恢复；目录失败→重试、真实空态、迟到响应；未保存/过期/阶段不符均有可见下一步；长图新增复制、键盘导航及属性定位。
- 表单与证据：候选审核专用账号和准备账号；折叠保留状态；缺项/无效 JSON 焦点；多轮/零值/未记录；详情与团队编辑同屏标签匹配；新组件 ID无冲突。
- 浏览器：桌面 1440/1600、390px 窄屏、短窗口；开合下拉/确认弹窗、遮罩/Escape、自然纵向滚动、无非画布整页横向溢出；实际服务页面截图与隔离交互用例分别记录。
- 工程：TypeScript、Vite、相关前端行为测试；原 P2/P3/Workspace 浏览器回归；premium-ui 配置的反馈浏览器；严格静态审计记录既存发现，不误报全站通过。
- 独立复核有意义的异步/草稿/权限边界，修复后再验证。前端优化不重新跑模型、不改后端规则。
