# 研发平台统一 Ant Design 改造计划

## 目标与边界

用户明确要求全平台统一使用 Ant Design，包含正在改造的动作模板完整画布。本轮接入实际 antd React 组件库、统一主题和共享控件，不仅模仿样式。保留当前页面、业务权限、固定版本、确认及未保存保护；不修改任务书引擎或资料。

采用 Ant Design 5 系列与 React 18，避免直接采用 v6 新浏览器基线影响内网 Chrome 104。构建锁定依赖，静态资源随本地部署，不使用 CDN、远程字体或额外在线服务。浏览器兼容结论区分代码与实际运行证据，不能以改 User-Agent 代替旧浏览器验证。

参考：Ant Design 数据展示和主题定制规范（https://ant.design/docs/spec/data-display/、https://5x.ant.design/docs/react/customize-theme/）。沿用 JONHON 标识，采用 Ant Design 的蓝色主操作、深色导航、白色工作面、紧凑信息层级。

## 统一视觉决定

- 主题由一个 ConfigProvider 和 TokenBridge 负责：主色 #1677ff、文字 #1f2329、页面 #f4f6f9、工作面 #ffffff、边线 #e4e8ef、导航 #001529。正文 14px；标题 22/18/16px；数据与版本使用等宽字体。控件 6px、面板 8px 圆角。
- 桌面导航 216px、顶部 64px；内容区 24px 间距，标题/操作同一行。页面保留自身滚动，宽表和画布各自滚动。
- 工作区以白色完整面板承载，目录与内容用分隔线组织，减少嵌套圆角大卡片。表格采用浅灰表头、清晰行线、紧凑操作列；只有可操作对象有 hover。
- 流程管理四类目录统一工具栏、卡片和分页。动作模板点击进入完整画布，节点与依赖如实来自固定版本。流程模板目录与画布是一体工作台，版本回溯单独页签。
- 使用真实 Ant Design 共享按钮、Select、Modal；画布节点、业务证据等特定内容消费同一主题，不替换其业务模型。所有对话仍能点遮罩关闭，忙碌/未保存保护延续既有合同。

## 执行分工

1. 主代理：安装依赖、ConfigProvider/中文 locale/主题桥接、全局样式与基础控件接入；整体验证和截图。
2. 流程工作面：flowManagement、workflowTemplateWorkbench、actionTemplateDetail；共享画布仅换视觉，不动节点几何与执行依赖。
3. 平台壳与管理工作面：导航/顶部、首页/项目目录、研发/知识/运营/系统、资源目录、账户区，统一令牌和间距。
4. 共享交互：StyledSelect、FeedbackDialog 与确认弹窗接入 Ant Design，保留原组件公共接口与访问控制。

## 验证

- TypeScript 与生产构建；固定版本动作详情和流程画布已有浏览器用例。
- 本地浏览：首页、项目空间、项目资料/当前成果/流程、研发管理、流程四分类、知识/运营、资源、设置及凭证弹窗；桌面和窄屏截图。
- 共用 Select 的键盘/禁用/组选项、弹窗焦点/遮罩/取消与确认行为；不打印凭证。
- 失败先复现具体文件/用例，定点修复，再跑完整受影响文件。只有明确依赖影响才扩展；不执行无筛选全量测试，不放宽断言或超时。
- 测试数据/模拟界面与真实业务区分；不新增正式项目决定、不调用任务书生成、不写用户资料。
