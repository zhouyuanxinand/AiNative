# 规格书文件名分类补齐

用户规则：`xxx规格书` 也是需求文件。批量拖入与文件选择均沿用现有后台分类入口。

1. 文件名包含“规格书”时按需求文件识别，覆盖技术规格书、组件规格书及产品规格书，不依赖模型调用。
2. 排除“产品规格”对“产品规格书”的重叠匹配；产品规格、产品规范及标准保留原分类。名称同时明确包含需求与规范标识时仍提示用途不明确。
3. 同步模型辅助分类的用途说明，不改变手工调整优先级、主文件选择和生成引擎。
4. 先用分类接口定点复现，再运行完整 `test_source_classification.py`，验证启用/禁用模型及分类不写入项目。仅检查必要运行状态，不运行全量、不提交代码。
