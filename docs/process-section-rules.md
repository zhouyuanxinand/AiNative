# 研制流程与章节保留规则

在平台 **规则中心 → 业务策略 → 研制流程与六性证据** 中，展开两个“章节保留”分组，可以修改保留流程、章节标题识别词及同步删除的关联章节。保存后对新任务生效，支持检查修改、版本记录及恢复。运行场景规则默认关联“附录A”。

规则存放于 `basic-service/app/src/service/config/development_process_policy.yaml` 的 `section_retention_rules`。生成与编辑使用同一套校验；`keep_processes` 勾选的流程保留模板原内容，未勾选的流程删除整个标题子树及关联章节。模板原本没有的章节不会凭空新增。

章节定位使用语义标题和 Word 标题层级，不依赖显示章节号或排列顺序。附录兼容受控模板中不含大纲级别的“附录标识”样式。删除包含章节下的正文、子标题、图片和表格，并在相邻章节处停止。主章节缺失时，关联附录仍按规则独立删除。正文中的附录引用不会被当作附录标题。

同时修正了填充“任务书编制依据”时的边界：识别后续附录，不再清除需要保留的附录 A，也保留文档末尾控制纸张、页边距和页眉页脚的分节属性。

每份输出的 `.process_rule_audit.json` 记录规则、当前流程、保留或删除动作、删除节点数以及关联章节删除节点数。实际删除的标题进入交付检查的章节排除清单。
