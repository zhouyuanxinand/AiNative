# 小航三维人物验证

悬浮小航使用原创蓝白飞行员模型，91个具名三维部件、16个姿态。WebGL按需绘制；踱步期间随往返方向改变视角。无WebGL或图形上下文丢失时切换到同一模型的透明帧图；动画资源也无法读取时保留静态人物。欢迎对话头像沿用同一造型。各版本共享脚底锚点和悬浮入口尺寸。

模型源为 `web/scripts/xiaohang-3d/model.py`，同目录 `bake.py` 生成浏览器模型数据、静态GLB、16帧图集与元数据、透明头像。GLB为站姿模型，浏览器的眨眼与挥手由姿态数据驱动。逐帧核对同名部件和锚点；精修后背面壳层没有原先的阶梯接缝。

定向验证（未执行全量或后端测试）：

- `xiaohang-3d.browser.mjs`：真实WebGL画面有可见人物；减少动态时保持静态；上下文丢失后自动切换，无WebGL时显示图集，动画资源不可用时显示静态头像。
- 完整 `xiaohang-walking.browser.mjs`：100/70/124px双脚交替、踏步居中、踱步往返、固定命中框与暂停归位。
- 完整 `xiaohang-aerospace.browser.mjs`：七种主题动作、人物/道具时长一致、暂停/恢复轮换、后台与减少动态。
- 完整 `xiaohang-companion.browser.mjs`：天气、对话、拖拽贴边、键盘、触屏与窄屏交互；5次隔离聊天、0页面错误。
- `npm run build`通过，独立3D渲染模块约6.7KB（gzip约3KB），既有主包分块体积提示仍在。构建产物中的GLB与源文件散列一致。

Chromium检查覆盖本地图形环境与软件后端，不代表所有手机GPU。三视图、从浏览器模型绘制的旋转预览和交互回执位于 `runtime/xiaohang-3d/`。
