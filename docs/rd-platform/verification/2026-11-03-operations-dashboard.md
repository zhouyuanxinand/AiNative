# 运营管理看板验收

日期2026-11-03；分支 `codex/rd-platform-rebuild-20261031`。代码未提交。本地入口：http://127.0.0.1:18370/?rd_view=operations 。

## 已完成

原运营页只列工作包，项目为空时仅一段提示。现按用户提供的研发管理平台演示版补为完整运营看板：

- 四项核心指标：可见项目、未完成工作包、去重后需要关注、执行完成率。
- 四个图表工作面：近14日计划与实际完成走势、资源容量与负荷状态、运行关注分类环图、资料与成果条图。
- 优先跟进事项与真实项目/案例回链。
- 进度与交付、执行与协同、成果与质量、流程与复用四组细分指标。
- 项目交付协调表及交付工期、资源工时、运行风险、资料质量四个台账页签。
- 关键词、运行状态、研发阶段、项目负责人统一筛选；所有区域共用同一只读投影。清空/重置、分页、刷新替换记录和窄屏表内滚动可用。

沿用Ant Design、RD Sans/RD Mono和矿物蓝工程主题。运营工作面单独按需加载，额外Table/图表工作面不在其它业务页面预先加载。

## 空值与日期

- 无记录仍显示完整指标/图表/分项/表头；计数0，零分母比率—，图表说明无样本，不画虚构曲线。
- 首次读取显示骨架与未知；错误显示可重试提示，不能据此判断0记录。已有数据时保留并标明上次读取的记录。
- 完成率为completed/(submitted+running+blocked+failed+completed)，不含草稿、未执行、取消，不表示正式交付通过。
- 逾期排除已完成/取消；缺失、无效或反向日期单独统计。7日窗口含今天共7个上海自然日，趋势取近14日有效日期。
- 表格、趋势和执行跨度共用有效completed_at优先、ended_at回退的规范化时间；无完整/非负起止样本不推算跨度，不将跨度换成人力工时。
- 关注计数按工作包去重；分类环图同一包可涉及多类，图中明确标为分类计数。义务数量为累计登记，不说成全部未闭整改。

## 限制

工时容量、预测工期、物料风险等级、正式质量整改、个人接单/审签责任尚无真实字段合同，本轮显示待接入而不是模拟值。当前项目API无分页，采用其已授权完整快照纯前端聚合；数据规模扩大时应把相同口径移到同权限服务端聚合。实测为本机Chromium，不替代内网Chrome104实机或任务书生成/正式交付验收。既有主包大小提示保留，未提高阈值掩盖。
