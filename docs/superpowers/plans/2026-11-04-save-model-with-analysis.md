# 模型选择随分析一并保存

用户已确认：选择模型后直接点击“分析上传资料”，无需另点保存。保持现有模型目录、最近使用、资料采用与任务书生成能力。

## 实施

1. 由项目页统一执行保存与分析，全程持有同一操作锁。模型改变时先执行 save_context，使用返回的项目版本调用分析；未改变时直接分析。
2. 保存失败保留选择且不分析；保存与分析分别按现有请求指纹保留重试幂等键。保存成功即更新选择基线和账号隔离的最近使用记录。
3. 移除独立保存按钮及“先保存模型”提示。保留模型下拉与分析按钮同行布局；新选文件仍需先上传。模型有改动时不能采用旧分析结果。
4. 使用隔离 API 的真实组件/项目页浏览器验证成功顺序、新版本、失败重试、重复点击、最近使用和窄屏布局。只运行受影响测试文件及前端构建，不运行全量，不调用真实模型或修改真实项目。

## 验收

选择模型后可以直接分析；没有独立保存入口。保存失败不发分析请求；分析失败后重试不重复保存。执行期间不可重复提交，未上传文件和旧识别结果保护仍有效。
