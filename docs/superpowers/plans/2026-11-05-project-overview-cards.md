# 项目空间外层总览卡片

用户确认：外层展示项目级数据，内层继续显示各流程详细卡片，不重复同一层级内容。

- 提取 ProjectOverviewCard，外层显示客户、产品、研发目标、流程总数、已完成流程数、需关注流程数、项目负责人及最近更新时间。
- 统计涵盖全部流程。完成和关注复用现有 projectCaseCardModel 的当前状态口径，排除历史无效失败与已完成流程；不编造项目百分比或截止时间。
- 保留前两条流程的继续办理/查看成果入口、查看全部、查看项目、删除及现有搜索/分页。内层 ProjectCaseCard 不改。
- 空项目数字为0，缺字段明确未设置/未记录。桌面项目卡片两列、窄屏单列；数字与基础资料分层展示。
- 在截图对应项目列表入口复现，再检查该入口及内层详情的导航、统计、缺值、搜索、删除取消和窄屏。只运行受影响浏览器文件与必要类型检查，不执行全量。
