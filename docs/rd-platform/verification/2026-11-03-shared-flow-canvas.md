# 共用流程画布验收

日期：2026-11-03。范围：流程模板、项目 FlowDesigner 与 Workspace 共同使用的 `FlowGraphEditor`，不改变任务书生成引擎。

## 已实现的交互

- 拖动节点；Esc 取消当前拖动并还原位置；Alt + 方向键移动所选节点。
- 拖动画布空白处平移、缩放、适应画布、自动排列；排列只修改坐标，不修改节点依赖和业务字段。
- 编辑节点名称、负责角色、多行交付物及已经接入的办理动作；技术标识、坐标和输入引用放在“高级信息”。
- 新增、复制、删除节点和连线；点击两个节点可建立先后关系，拒绝自连线、重复连接和循环。必需步骤与业务确认节点不可删除，页面解释原因。
- 外层通过 `draftReducer` 统一撤销/重做。取消动作引用使用显式 `null` 操作，保存后的节点移除引用字段；撤销可以恢复。
- 只读历史版本支持查看、定位与缩放，禁用图修改。没有添加脚本、执行器代码或表达式输入框。

## 内网 HTTP 兼容复核

独立复核指出节点和连线直接调用 `crypto.randomUUID()`，在普通内网 HTTP 中该 API 不可用。先禁用 API 运行浏览器用例，复现连线失败；然后统一改用已有 `makeRequestKey()` 兼容实现。修复后上述 9 组用例和 TypeScript 检查通过。浏览器测试模拟 API 缺失，尚未连接内网浏览器实机。

同时将保留的 `BusinessWorkflowPanel` 中“另存为新业务模板”的唯一标识生成调用替换为相同兼容方法，保留 `workflow-` 前缀及原有业务行为。该旧入口未纳入上述画布组件用例；最终生产构建由整体验收执行。

## 拖动后的连线方向复核

新增独立 `flowEdgeGeometry.ts`，输入起点、终点及其他节点的实时矩形，返回 SVG 正交路径、各折点、两端连接边、路径中点和路径范围。节点尺寸由调用方传入，不假定固定宽高；调用方需传入拖动预览位置，并将箭头标记的尖端对齐路径末端。

优先选择四边之间可行的短路径；被其他节点挡住时尝试节点外侧通道，复杂交错障碍使用带转弯代价的路径搜索。第一段向源节点外侧，末段向目标节点内侧，路径不穿过节点内部。水平、垂直、反向、近距离斜向、交错障碍、不等尺寸、八方向连续移动、小数坐标平移及重叠矩形共 7 组几何测试通过，TypeScript 检查通过。36 节点布局连续计算 350 条连线的本机烟测约 28 毫秒，仅用于本次开发检查，不作为性能保证。

边界：不解决节点本身的遮挡，也不承诺不同连线彼此不交叉；包含关系使全部连接口不可见时，返回 `clear=false`，重叠返回 `overlapping=true`。绕行可能超出节点包围盒，调用方需根据 `bounds` 留出画布空间。此处记录几何模块验证，页面交互和箭头样式由集成后的浏览器验收确认。
