# 规范对照建议并发验证

## 修改

- 原实现每 15 条需求一批，串行等待；现改为每次核对最多 3 批在途，完成并校验后再补充下一批。
- 规范只提取一次，各批读取同一输入快照与完整主规范。批内按需求 ID 校验，批间按原始位置合并，保留需求版本与证据定位。
- 使用现有模型和 OA 身份上下文传播；共享 240 秒预算，每次模型请求最长 120 秒、最多 2 次传输尝试。沿用完整引文和指标兼容性校验。
- 任一批失败停止派发后续任务，已经开始的网络请求会等待结束或超时。全部成功才由原存储事务复核版本后保存，保留失败前已有结果和用户决定。
- 未调整原任务书生成引擎、审批/采纳语义、前端响应协议；没有提交代码。
