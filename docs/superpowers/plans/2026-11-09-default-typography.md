# 默认字号调整计划

用户确认满意的截图使用浏览器 90% 缩放。本次将研发平台默认文字大小调整为接近该效果，用户可在浏览器 100% 下使用。

## 实施范围

1. 为现有字号体系设置统一 0.9 比例，使 Ant Design 控件、页面正文、侧栏、标题和挂载到 body 的弹窗/下拉保持一致。
2. 正文 14 → 12.6px，主菜单 16 → 14.4px，页标题 24 → 21.6px；较小辅助文字保留原大小，缩小后的字号不低于 12px。
3. 将研发界面局部固定文字字号接到统一字号变量，保持现有层级和字重。保留按钮点击区域、间距、画布坐标以及文档正文的独立排版。
4. 不设置整页 CSS zoom，不改变浏览器缩放或持久化用户的浏览器配置。

## 验证

- 审查差异，确认本轮只涉及界面字号和设计说明。
- 执行前端生产构建与字体静态检测，不执行无筛选全量测试。
- 浏览器可用时集中检查研发管理、项目列表及新建项目弹窗；当前浏览器工具缺失运行时模块，若无法连接，在交付说明中明确未完成现场视觉验证。

## 实施结果

- 已统一 Ant Design 与研发页面字号，保留小号辅助文字、控件尺寸、画布节点及文档/原文预览。
- TypeScript 检查、Vite 生产构建、字体静态检查和差异空白检查通过；构建仍有大体积 bundle 提示。本地 18370 返回 HTTP 200。
- 独立只读审查确认机械 CSS 变更仅涉及字体声明，修正了两处应保留的加号图标大小。未执行全量测试；浏览器运行模块缺失，本次未完成实际截图复核。
