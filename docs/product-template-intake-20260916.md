## 接入实现

1. 独立产品 Profile 控制指标词表来源。新增低频产品只引用通用词表；新导入模板使用模板明确列出的指标名称，不自动混入电连接器、光学或射频词表。指标名称不携带默认指标数值，数值仍须来自本次需求或规范。
2. 五个新模板家族分别配置章节映射。按标题、父标题及标题层级定位，未把章节编号或文件中的绝对位置当作业务身份。线缆组件支持接线、捆扎、防波套、热缩、锦纶丝套、灌胶和塑封章节；液冷模板支持对应安装、开孔和接口要求。
3. 原低频映射补充技术指标和可靠性章节的层级、父标题约束，避免匹配编写说明或可靠性子章节。
4. 滤波、液冷管路、机箱和冷板原模板只包含一套“研制经费预算”。新增独立单预算策略，目前仅支持非中央研究院；选择中央研究院会明确拒绝，不伪造经济性分析章节。原低频、射频和线缆模板继续使用原双分支策略。
5. 模板候选生成器保留来源分类规则、内容优先级、容器分类与空槽处理策略，避免自动接入时丢失这些业务规则。
6. 机箱接口容器无法细分的原文保留在接口“其他要求”；线缆处理容器无法细分的原文保留在顾客“其他要求”，这些候选路由仍需业务核对。温度冲击与机械冲击按当前产品指标词表区分，机箱“环境温度”与“工作温度”保留独立指标身份。

本次没有用模板中的示例数值补齐输入，也没有根据产品名称猜测压力、频率、寿命等要求。模板未提供的专用指标、指标别名、互换性等章节的处理方式，仍需真实样例与逐章规则确认。
