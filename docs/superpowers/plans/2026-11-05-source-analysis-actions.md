# 资料分析后的卡片与操作布局

用户要求：分析完成后收起编制资料，将确认采用移到重新分析资料右边。

## 实施范围

1. 编制资料提供可用键盘操作的展开／收起入口及文件数量。当前有效分析结果默认收起；成功分析后收起。失败不改变用户展开状态，结果失效时展开，待上传队列保持可见。隐藏内容时保持上传组件挂载，保留文件、分类、主文件选择与重试状态。
2. 模型、重新分析、确认采用组成一个操作行。确认采用位于最右侧并作为主操作，重新分析作为次操作；无结果时仍以分析为主操作。小屏模型独占一行，操作按钮在下一行靠右排列。
3. 保留分析、采用的版本校验、禁用条件、并发锁、失败重试与全屏审阅功能；删除页面底部重复采用入口。

## 验证

- 在现有资料分析浏览器用例验证成功／失败／过期结果的折叠行为、手动展开与待上传保护，以及两按钮相对位置与窄屏布局。
- 按实际影响验证批量上传和模型选择浏览器文件；执行前端构建，不运行无筛选全量测试。
- 检查实际本地页面，不发起模型请求或修改用户数据。
