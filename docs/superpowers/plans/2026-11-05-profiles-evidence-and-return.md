# 画像入口、证据来源与办理位置恢复开发计划

**目标：** 按六份主题方案与演示平台的业务归属补齐画像查看入口，压缩办理页重复抬头，往返项目流程后恢复最近工作面及阅读位置。

## 依据与范围

- 01 §12.8.3（3665–3669）：研发管理固定“客户画像／产品画像／项目与任务”；详情与目录互斥，返回恢复筛选和页码。
- 01 §14.2.8、§17.11.1：项目可查看相关画像摘要、引用理由与版本；历史偏好不是已确认客户要求。
- 02 §5.1、§5.4–5.5：画像主档和发布版本归 K-box；项目采用版不随新版静默覆盖。04 §1.4.5、05 §12.3、06 §8.1.1 同样要求来源、适用范围和确认边界。
- 当前仅有项目客户／产品登记、上传资料及分析/确认记录，没有企业画像主档接口。先实现基于已授权项目记录的画像查看，不把名称当作跨项目统一实体 ID，不伪造正式发布版、标准证据或企业实测能力。
- 延用 Ant Design、工程平台现有颜色与字体；本轮不改任务书生成引擎、后端业务决定和既有未提交修改。

## 实施拆分

### 1. 导航恢复
- 文件：RdPlatformPage.tsx、CaseWorkspace.tsx、必要的导航辅助文件；新增定向浏览器用例。
- 先复现“当前成果→项目流程→当前成果”覆盖为 current 的问题。
- 点击当前成果恢复当前案例最近的可办理子页；显式成果概览仍进入概览，不劫持显式深链和浏览器前后退。
- 按工作面分别保留滚动位置，隐藏页面不清除编辑内容；账号和项目／流程隔离，已失效步骤按现有业务进度回落。
- 验证资料分析、需求填写草稿、滚动、反复切换、另一个流程不串页。

### 2. 画像查看
- 文件：PlatformManagement.tsx、新的画像目录／详情组件、局部 CSS；定向浏览器用例。
- 研发管理增加客户画像、产品画像、项目与任务三个页签。
- 当前画像由项目登记与原文引用形成“项目资料视图”，记录稳定项目／流程 ID 和来源版本，缺失项显示未登记；画像主档状态显示尚未接入。
- 客户展示登记信息、相关项目和来源可核对的要求；产品展示型号/参数、来源指标和适用记录，明确区别原文要求与实际验证，不据文字相似度归并客户或产品。
- 目录支持查询、分页、详情和返回；显示请求中、失败、空数据和过期来源状态。项目内复用同一画像内容入口，不复制第二套数据。
- 本轮不实现企业画像审核/发布，也不宣称这些项目汇总已作为 K-box 发布画像被模型引用。

### 3. 证据与页面减重
- 所有需求清单“AI 来源”统一为“证据来源”，包括窄屏标签与审阅界面。
- 选中业务流程时移除红框中的工具条与客户/产品/研发目标大块摘要，保留项目总览管理操作，背景信息在资料与依据中查看。
- 证据仍可打开当前来源和原文，适配项目登记来源标签；补充与当前项目关联的画像查看入口，保留原页面和草稿。

## 验证与交付

- 只运行导航、画像、需求清单直接受影响的浏览器文件；失败先定点复现，再完整受影响文件。执行前端类型与构建检查，不执行无筛选全量。
- 保留原有有效断言与超时；如旧测试断言明确被本轮用户要求替代，改为新行为断言并记录原因，不删除无关覆盖。
- 检查桌面与窄屏截图、证据弹层返回、无数据和真实本地页面加载。
- 记录方案评估结论、实现边界和测试结果，不自动提交本轮代码。

## 实施结果与验证

- 研发管理新增三页签；画像详情复用到办理页弹层。企业主档尚未接入时，只显示当前授权项目的登记、原文及采用记录，未将演示数据写入真实项目。
- 办理页移除重复项目抬头，需求清单及审阅统一使用“证据来源”。原文依据与当前采用值依据分别保留。
- 当前成果恢复最近办理子页、滚动及未提交草稿；显式成果概览与浏览器前后退保留原有语义。会话接口暂时失败保留草稿并暂停提交，就地重新核验恢复；身份失效仍按原权限处理。
- 画像查询键加入应用路由白名单，避免刷新时丢失页签、查询、页码和详情。
- 定向完整文件通过：rd-source-analysis.browser.mjs、rd-requirement-decisions.browser.mjs、rd-case-view-return.browser.mjs、rd-project-profiles.browser.mjs、rd-management-return.browser.mjs、rd-navigation-history.browser.mjs。失败均先定点复现修正，再执行完整受影响文件；未运行无筛选全量。
- 新增往返测试共 13 项检查，覆盖滚动、草稿、不同流程隔离及会话 503 恢复。画像测试覆盖同名项目隔离、历史来源、采用依据、刷新及空数据/失败/加载状态；无页面异常和写请求。
- 最终前端类型检查和生产构建通过；保留现有大包体积提示。git diff --check 通过。桌面与窄屏截图已检查。
- 浏览器交互测试使用隔离夹具。另以实际本地服务执行只读加载检查：新浏览器身份下没有可见项目，空目录及页面加载正常；未据此宣称真实用户的完整生成流程已重跑。画像主档和本体/K-box 集成仍待后续接口。
