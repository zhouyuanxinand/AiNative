# 运营管理看板补齐计划

## 依据与目标

用户提供 `D:/桌面/研发管理平台-主包 1021/研发管理平台演示版/`，要求运营管理参照演示版展示内容，无数据也有完整处理，有数据后使用真实数据，视觉效果更好。已读取演示版 operations-dashboard.js、research-operations-data.js；演示版包括角色关注指标、项目/任务分布、协调建议、进度/质量/采用指标、项目明细与交付/资源/风险/资料整改台账。

当前正式页只有工作包列表，直接使用现有已授权 `/api/rd/projects` 记录。保留服务端权限过滤，纯只读聚合，不将演示seed写入项目或混入真实统计。先在真实数据范围内提供完整看板；演示版独有的人工责任分工、电子审签、容量工时与独立整改台账未接入的指标明确显示待接入。当前后端没有可切换企业角色的合同，因此使用业务内容分区，不增加冒充角色的权限切换。

## 设计

- 统一 Ant Design、RD Sans / RD Mono、矿物蓝主题。上方四项核心指标，中部项目阶段/工作包状态图表，关注事项与四组运营指标，下方项目协调和工作包明细，配套台账按页签查看。
- 关键词、执行状态、研发阶段、项目负责人共同过滤同一投影。筛选不匹配单独说明并可重置；点击项目或工作包返回已有项目流程。界面只读，不触发运行、审批或生成。
- 空数据保留完整统计/图表/表头与引导：数量0、无分母比率—、无图表样本显示暂无记录。加载用骨架/占位，错误可重试；上次数据存在时标记过期，不将失败当0。
- 已登记计划截止日期才能计算逾期/7日到期；已完成/取消不算逾期；未登记日期独立计数。执行完成率仅为执行状态统计，不代表工程核验/接受/正式交付通过。
- 成果文件、需求、来源、复用候选、流程模板采用等只读真实字段；工时和资源容量不从耗时推造，未取得时不展示0h或虚构负荷曲线。
- 图表使用可访问SVG/语义列表，颜色外附数量/状态名称，不引入CDN/远程图表或大型新增依赖。窄屏卡片堆叠，宽表内部滚动，页面不横向溢出。

## 模块与执行

1. `operationsProjection.ts` 与对应定点Node测试：统一筛选、状态/阶段/日期、指标、关注排序与项目/工作包数据投影。显式now注入便于验证日期边界。
2. `OperationsDashboard.tsx` / `operationsDashboard.css`：可复用统计卡、阶段条图/状态图、分组指标、关注事项、项目表格、执行明细及台账空状态；AntD组件、页内筛选、重试/刷新/分页及来源说明。
3. `PlatformManagement.tsx`：运营视图委托专用看板，移除旧重复列表，不影响其他视图。
4. 定点浏览器fixture验证有数据/空数据/筛选空/刷新/错误及恢复、真实回链与390px；实际平台只读截图。测试失败按失败文件定点修复后复验，保留断言和超时；不执行无筛选全量。
5. 完成构建、视觉截图复核、DESIGN/UX合同和验收记录；不提交代码。
