# 新增产品类型与模板接入（2026-09-20）

后续更新：2026-09-21 已补齐并启用光缆组件及液冷连接器模板，详见 [光缆与液冷连接器模板接入](光缆与液冷连接器模板接入-20260921.md)。以下为 2026-09-20 的接入记录。

本次新增 9 个产品类型，其中 8 类已启用军品配置。光缆组件因未提供模板保留为“模板待补充”，不能被调试开关绕过或套用其他模板。

| 产品类型 | 受控模板 |
| --- | --- |
| 光连接器 | 研制任务书（光纤连接器） |
| 印制板组件 | 研制任务书（背板） |
| 光缆组件 | 未提供，暂不生成 |
| 机箱、安装板、光布线箱 | 研制任务书（机箱） |
| 安装架、设备柜、显控台 | 研制任务书（系统集成+整机布线） |

产品选择、模板目录、故障数据库均读取同一产品目录。共享模板的产品仍有独立产品身份和 profile，故障记录不因共享模板而跨产品或跨系列匹配。印制板组件不替换原有“高速连接器-高速背板连接器”，机箱不替换液冷机箱。

## 生成结构

- 光连接器、机箱使用各自原模板的四列技术指标表，仅从本次来源提取数值。
- 印制板组件和系统集成按真实章节复制原文、表格和图片，不额外构造指标表。分类映射与 profile 同时声明 `technical_requirements_mode: sections`，目录入口校验二者一致。
- 章节式模板继续检查标准、原文覆盖、语义落章、故障库和研制流程。交付使用与输出 Word 绑定的语义审计和覆盖台账，不伪造指标审计通过结果。
- 全新保留 QFD；改型 I/II/III 删除 QFD。全新与改型 I 保留运行场景及附录 A，改型 II/III 同步删除。
- 改型任务按六性父章节、标题别名与实际子分类证据决定保留，避免误删定量、定性或试验要求。系统模板的“初步失效模式分析”同样遵循流程删节。
- 材料要求继续沿用现有进入工艺章节的规则。
- 故障表填写和最终校验共用五个语义字段，兼容系统模板原有简称表头，仍检查独立列和字段顺序。

## 模板维护

四份 Word 模板已经纳入模板目录，支持下载、替换、启用和历史版本恢复。章节式模板替换时校验其真实技术叶子章节，不强制不存在的指标表。

光纤连接器、背板、机箱由用户提供的 DOC 转为 DOCX；系统集成 DOCX 原样复制。来源路径、SHA-256、结构与转换记录见 `source_manifest.json`。转换对照正文、表格、节、图和页数，并渲染检查 83 页。

本次军品以外的质量体系未另行开放。印制板使用原模板单预算策略（非中央研究院）；系统集成原模板没有经费预算分支，显式采用无预算分支策略，不补造章节。

## 验证与使用

本地开发平台地址为 http://127.0.0.1:5173/ 。刷新页面后可选择新增类型。验证包括真实模板填充、源表格/加粗保留、流程矩阵、动态替换、故障记录匹配和浏览器目录联动；采用合成输入，不依赖外部模型服务。

印制板 47 类、系统集成 64 类合成来源已经完成原文复制、排版、覆盖率、语义落章与最终交付检查。资料不完整时仍执行原质量检查：例如仅输入绝缘电阻条款，系统模板保留的产品示意图和振动谱图题可能提示缺少图片，不因新增类型而关闭检查。

详细转换、填充和页面验证记录在 `basic-service/app/runtime/product-expansion-20260920/`。本次源码改动尚未重新构建历史 Docker 镜像或 tar 包。
