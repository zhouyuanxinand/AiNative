# 模板目录自动更新验证

日期：2026-11-04。分支：`codex/rd-platform-rebuild-20261031`。

本轮仅实现用户确认的第一项：新建项目及新增流程弹窗去掉常驻“刷新模板目录”，目录在打开弹窗、从流程管理同页返回、弹窗所在页面重新获得焦点或可见时自动读取。未修改六项业务参数和任务书生成引擎。

用户已经选择的模板 id/version/digest 保持不变，新的目录版本可以手动选择；创建中、部分创建已落盘、结果未知或冲突待核对时暂停自动刷新。读取失败保留填写，在错误处显示重新读取；空目录明确提示并禁止创建。

独立复查发现旧目录慢请求会使返回事件被跳过，已修正为取消旧读取并获取最新目录。延迟响应夹具先复现失败，再验证新目录不被迟到旧响应覆盖。

## 验证范围

- `web/tests/rd-project-workflow-entry.browser.mjs`：完整文件 11/11 组通过，原有超时和固定版本/六节点/终态/窄屏断言保留。
- 覆盖新建与新增流程自动读取、同页返回、focus/visibility 合并、隐藏页面不读、固定选择、慢响应竞态、创建中与未知结果的同键重试、空态和失败恢复。
- 所有 API 使用隔离夹具：真实 API 请求 0、夹具写请求 4、页面异常 0、未知请求 0。未创建或删除真实项目，未调用生成模型。
