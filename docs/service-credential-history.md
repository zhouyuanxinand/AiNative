# 服务凭证历史

侧边栏底部打开“服务凭证设置”，在“历史凭证”中选择环境，再点“使用此凭证”。切换成功后自动刷新模型列表，后续请求使用新凭证。仅选择下拉项不会切换；存在未保存修改时，会先提示确认放弃。设置仍只包含“模型”。

每次保存会保留新旧凭证；相同完整凭证重复保存不会增加重复记录。历史显示环境名称、服务地址、App ID、租户和时间，不返回历史记录的 API Key。当前凭证仍支持按原有方式点击“显示”查看。凭证不写入浏览器本地存储。

“删除记录”只删除选中的历史项，不改变当前连接；当前使用项不能删除。“恢复本组默认”先还原表单，再点“保存凭证”生效。

## 模型连通性与响应时间

设置弹窗下方新增“模型连通性与响应时间”。可先点击“读取模型列表”，选择返回的模型；也可以直接填写网关支持的完整模型名称，再点击“测试连通性”。支持按返回的模型 ID 区分同名模型，手动改名不会携带之前模型的 ID。

测试使用当前表单凭证，恢复默认后使用部署默认值；无需先保存。测试不写入凭证或历史，不影响已保存环境及其他任务。读取目录成功只说明目录可访问，点击“测试连通性”才会发送一条不含业务文档的简短请求。目录读取失败时仍可手动指定已知模型进行测试。

结果显示成功或失败原因、测试模型、耗时及测试时间。响应耗时从服务端开始测试到收到完整响应或失败为止，包含网络及模型处理时间，不是首字延迟，也不代表文档生成总耗时。目录最长等待 10 秒，模型请求最长等待 45 秒，均不自动重试。鉴权失败、服务不可用、超时、无效格式、空文本、截断和未完成响应不会显示成功。

编辑凭证、切换环境、恢复默认或关闭弹窗会清除旧结果并停止等待；更换模型会清除该模型之前的测试结果。“取消测试”停止本次等待。模型请求和测试结果均不写入浏览器本地存储，服务不会向页面返回模型测试正文或鉴权异常原文。

## 部署预存环境

私有 `.env` 可通过 `JTB_SERVICE_CREDENTIAL_PRESETS` 配置命名环境，格式见 `.env.example`。预置记录在首次打开设置时导入，导入不会激活环境。相同凭证只导入一次，手动删除后重启不会重新出现。修改预置记录的凭证内容会作为新记录导入。

源码部署需通过现有 `JTB_SHARED_ENV_FILE` 或进程环境加载私有 `.env`。当前 Dockerfile 会将服务根 `.env` 放入镜像中的服务配置位置，Docker Compose 也会通过 `env_file` 注入。因此，后续使用当前工作树构建镜像即可携带已预存环境；旧镜像不会自动包含这次代码和配置。Git 不包含私有 `.env`，仅同步 Git 代码时需单独携带该文件或设置同名环境变量。

当前设置和历史保存在 `basic-service/app/runtime/service_credentials.sqlite3`（可用 `JTB_SERVICE_CREDENTIALS_DB` 指定路径）。Compose 的 `taskbook-runtime` 数据卷会保留保存、切换和删除结果；迁移已有历史应保留此数据库。读取旧版数据库时会自动补齐历史结构，当前凭证继续有效。

## 接口

所有接口沿用 `X-Credential-Settings: 1` 与同站请求限制，响应禁止缓存。

| 请求 | 行为 |
| --- | --- |
| `GET /api/settings/credentials` | 当前配置、部署默认值及不含密钥的历史摘要 |
| `PUT /api/settings/credentials` | 保存当前配置并记录历史 |
| `POST /api/settings/credentials/history/{id}/activate` | 使用指定历史凭证 |
| `DELETE /api/settings/credentials/history/{id}` | 删除非当前使用的历史项 |
| `POST /api/settings/credentials/test/models` | 用当前表单凭证读取模型目录并返回耗时 |
| `POST /api/settings/credentials/test` | 对指定模型发起单次连通性测试并返回完整响应耗时 |

两项测试请求均传入 `credentials: {model: {...}}`，`model: null` 表示部署默认。聊天测试还传入完整 `model` 名称和可选 `model_id`。格式错误为 HTTP 400；实际连通性失败为 HTTP 200、`success: false`，带安全的 `error_code` 和中文 `message`。响应均有 `response_time_ms` 和 `checked_at`。

2026-09-21 验证：探测与既有凭证共 79 项后端测试通过，前端构建及连通性、凭证历史、保存恢复三套浏览器测试通过。真实外网目录返回 15 个模型；`dashscope/qwen3.5-plus` 实测成功，完整响应耗时约 1.63 秒。测试前后保存凭证与历史一致。该耗时仅是本次实测，内网模型需部署到可达内网后按实际环境测试。
